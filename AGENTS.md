# AGENTS.md

Правила проекта для ИИ-агентов (Claude Code, Codex, OpenCode, локальные модели).
Держи этот файл коротким: агенты читают его на каждом шаге.

## О проекте

Демо summary-бота для мессенджера MAX: `bot-gateway` (webhook), `api`, `worker`; режимы пересказа документов и ссылок.

Карточка проекта — в `~/Vaults/Main/20 Проекты/` (та, где `путь: ~/Code/personal/max-summary-bot`).

## Команды

- `pnpm install` — зависимости
- `pnpm run dev` — pnpm -r --parallel --filter @max-summary/bot-gateway --filte
- `pnpm run build` — tsc -b
- `pnpm run typecheck` — tsc -b --force

## Как проверить, что всё работает

Задача **не готова**, пока эти проверки не прошли и их вывод не показан:

- `pnpm run build`
- `pnpm run typecheck`

Для интерфейса открой страницу через Playwright, сделай скриншот и посмотри на него.

## Правила

- Работай маленькими шагами и делай `git commit` после каждого рабочего шага.
- Не делай `git push`, не трогай `main`/`master`, не меняй `.env` и секреты.
- Не добавляй зависимости без необходимости. Если добавил, напиши об этом в PROGRESS.md.
- Сначала читай существующий код и пиши в его стиле.
- Если требования неясны, выбери самый разумный вариант и запиши решение в PROGRESS.md. Не останавливайся ради вопроса.

## PROGRESS.md — передача работы

Работу может продолжить другой агент: ты сам после сброса контекста, Codex или локальная модель.
После каждого значимого шага обновляй `PROGRESS.md` в корне:

```markdown
## Цель
## Сделано
## Осталось
## Как проверить
## Решения и находки
```

## Локальная модель

`local-llm "инструкция" < файл` — бесплатная локальная модель для черновой работы: пересказать длинный лог, сделать черновик, сгенерировать тестовые данные.
Её ответы проверяй сам, финальные решения принимай сам.
